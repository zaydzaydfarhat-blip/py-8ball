# 🎱 py-8ball

A simple Magic 8-Ball game that runs right in your terminal. Type a question and get a random **yes**, **no**, or **maybe** answer!

## Run it

You only need Python 3. No extra packages are required.

```bash
python3 main.py
```

## Play

1. Start the game with `python3 main.py`.
2. Type any question and press Enter.
3. Get a random answer from the 8-Ball.
4. Type `q`, `quit`, or `exit` to leave.

Works on Linux, Debian, Arch Linux, and Termux (Android).
